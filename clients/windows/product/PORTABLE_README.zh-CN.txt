Oracle Proxy 0.3.0-rc23 · Windows 10/11 x64 便携验收包

本包为未签名候选版，不能保证免除SmartScreen或“未知发布者”提示。首次安装服务需要UAC；日常连接不需要管理员权限。rc20已实机验证重启后恢复与双栈出口，本版本仍需实机回归，真正登录前全程防泄漏与可信发布签名尚待专项验收。服务器就绪时支持 IPv4 / IPv6 双栈，均经 WireGuard，并共享设备配额与防泄漏保护；服务器未就绪时仍阻断 IPv6。

运行时与升级
本包自带 .NET 10 LTS 运行时，不依赖电脑另装 .NET 8 或 .NET 10。升级请先正常退出旧客户端，再运行新版安装包或完整解压新版并升级服务；不要先卸载，避免删除本机设备身份。运行时安全补丁由后续客户端版本随包更新，单独更新系统中的共享 .NET 不会替换本包运行时。

首次使用与设备确认
1. 完整解压ZIP，保留三个程序文件在一起，不要直接在ZIP内运行。
2. 打开OracleProxy.exe，点击“安装 / 升级服务”并确认UAC。无需安装.NET、WireSock、WireGuard GUI或FlClash。
3. 使用管理员分配的账号密码登录。在“02 账号、用量与设备”核对本机名称和识别码，可填写便于辨认的设备名称。
4. 勾选“这是我的设备”，点击“确认并登记此设备”。服务器确认后才启用“连接”；确认登记本身不会连接VPN。
5. 选择“WireGuard / UDP”或“自动（UDP优先）”，再点击连接。服务器支持时日常使用原生UDP8443，无需点击诊断测试按钮；QUIC / HTTP/3可选，HTTPS仅自动兜底。实际协议和验证出口始终明确显示。
6. 日常操作无需管理员权限。旧版升级前先断开并退出，再完整解压新版并升级服务。账号和本机密钥保留；旧设备首次升级需确认归属，不再占一个设备名额，已确认设备重复登录无需再次登记。

账号与设备
账号由管理员创建，不开放自行注册。登录本身不占名额；默认最多三台，以管理员为账号设置的限制为准。相同本机密钥重复登记复用原名额。名额满时请联系管理员撤销旧设备，不要反复卸载重装。
登录后账号密码输入框收起，需重新登录时点击“切换账号”；已登记设备详情及系统维护按钮默认收起，点击对应入口展开。
账号区显示用量进度、已用/总额/剩余、到期日、已登记设备数量，以及当前账号自己的设备名称和识别码。已登记数量不是当前在线数量。
识别码来自本机公钥，不采集MAC地址或硬件序列号。管理员可查看待确认登录、设备归属与确认时间，并核对客户端状态、实际握手和用量。客户端上报状态不代替服务器流量统计。
密码仅用于当次登录，不持久化；私钥和令牌由SYSTEM服务通过DPAPI保护，普通界面不接收私钥或令牌。

连接、断开与恢复
连接区显示本次验证的出口IP、实际协议、隧道HTTP延迟和本机VPN网卡速率。速率约每秒更新，与服务器月用量统计口径不同。首次连接或网络变化可能需等待；预备通道不接管普通应用流量，也不代表VPN已连接。
显示“已保护 · 等待连接”时，尚未确认出口，不代表连接成功。失败或意外退出继续保护，普通应用不会自动绕过VPN。
“断开并恢复直连”恢复直连并保留快速重连；正常关闭窗口会停止核心、恢复直连并退出。系统服务空闲待命，账号登录保留。强制结束界面不是正常退出。
若断开未完成，请使用“03 诊断与测试”中的“恢复直连（UAC）”；不要关闭系统防火墙。连接诊断仅导出固定状态和错误码，不含账号密码、令牌或密钥。

UU与其他工具
UU根据安装记录和进程自动发现，不依赖盘符；仅核验通过的网易签名和安全目录获得直连例外。遇到提示可在断开状态使用“重新识别UU”和“UU检查详情”。
“修复UU权限（UAC）”仅处理符合条件安装中明确的普通用户修改授权，先备份，再收紧为读取和执行；不会修改程序内容或停止UU。“恢复UU权限（UAC）”核对对象及权限未被其他工具改变后恢复备份。日常升级或设备确认不需要重复操作UU权限。
若GitHub打不开，可使用“GitHub连通性”查看Steam++等工具是否仍将域名指向本机。诊断不会修改hosts、关闭软件或更改证书设置。

卸载与开源许可
“卸载”会停止隧道、恢复直连、删除服务和本机密钥；服务器设备历史与用量仍保留，请联系管理员撤销旧记录释放名额。删除密钥后重装会产生新设备身份。
