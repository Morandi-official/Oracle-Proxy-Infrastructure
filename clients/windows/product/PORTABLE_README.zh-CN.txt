Oracle Proxy 0.3.0-rc1 · Windows 10/11 x64 便携验收包

本包尚未通过真实 UU 会话和物理重启验收，应用未进行发行者签名，不是正式版。
请仅在可本地操作、断网后能自行恢复的测试电脑使用。
当前服务器未启用 IPv6 出口：IPv6 被阻断，IPv4、TCP、UDP 与 DNS 经 WireGuard。

使用步骤
1. 将完整 ZIP 解压到本地文件夹，保留三个程序文件在一起，不要直接在 ZIP 内运行。
2. 打开 OracleProxy.exe，点击“安装 / 升级服务”并确认 UAC。无需安装 .NET、WireSock、WireGuard GUI 或 FlClash。
3. 使用管理员分配的账号密码登录，点击连接。设备自动登记，私钥只保存在本机 SYSTEM 加密存储。
4. 日常操作无需管理员权限；界面显示状态、延迟、用量进度、限额和到期日。
5. 点击“断开并恢复直连”才会主动取消保护。关闭窗口不会断开系统服务中的 VPN。

UU 远程
程序根据安装记录和运行进程自动发现 UU，校验网易数字签名及文件/目录权限，不依赖盘符或固定安装路径。
已发现但不安全的安装会阻止连接，请先处理界面提示。真实登录会话在 VPN 故障时能否保持在线尚未验收。
请先在本机测试，再用于只能通过 UU 访问的电脑。

紧急恢复
异常时普通应用可能继续被阻断，这是连接保护的一部分。
在原便携目录打开 OracleProxy.exe，点击“恢复直连（UAC）”并确认；该操作关闭自动连接并保留可用密钥。
如果界面不可用，可在本机管理员终端执行同一目录的 OracleProxy.exe --recover。
不要删除服务、加密状态文件或手动关闭系统防火墙来代替恢复。

升级与卸载
升级：完整解压新版，运行新版界面的“安装 / 升级服务”；启动失败自动恢复旧服务文件，账号密钥保留。
卸载：点击“卸载”，确认后恢复直连并删除本产品服务、本机密钥和运行缓存。
服务器仍保留设备历史和用量；如需释放设备名额，请联系管理员撤销旧设备。
首次 UAC 安装后的系统文件存放于 Program Files，便携目录可以移动，但不能只复制单个 EXE。

安全与许可
SHA256SUMS.txt 用于文件完整性核对，不是发行者签名。不要关闭 Windows 安全防护来强制运行未知文件。
三个程序文件必须来自同一次构建；服务会验证核心及防护模块的内置哈希。
