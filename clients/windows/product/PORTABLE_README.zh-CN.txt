Proxy 0.3.0-rc33 · Windows 10/11 x64

未签名预发行版，Windows 仍可能提示未知发布者。本包自带 .NET 10 LTS，无需另装运行时。

安装与登录
1. 安装版运行 setup EXE；便携版完整解压后打开 Proxy.exe，保留 runtime 组件目录，不在 ZIP 内运行。
2. 软件会先检查系统服务，缺失或版本不匹配时自动安装／升级，请确认 Windows UAC 授权；准备完成后才允许登录。已是匹配版本时不会重复申请授权，不需要手动点击安装服务。
3. 输入管理员分配的账号和密码。可勾选“记住登录”，最多 30 天；保存的是加密登录令牌，不保存密码。未勾选时正常退出需下次重新登录，主动退出账号会清除记忆。
4. 登录时自动检查并登记本机，成功后进入连接页面。重复登录或升级复用现有设备身份，不额外占名额。名额满时联系管理员撤销旧设备。

升级请先断开并退出旧版，不要先卸载，以免删除本机密钥。从旧版升级后需重新登录一次；已登记设备保持不变。

连接与退出
普通“自动”和“WireGuard / UDP”使用自适应端口，优先 443，备用 8443，并复用同一网络近期验证成功的端口。QUIC 可选，HTTPS 自动兜底。“原生 UDP 8443 测试”仅为固定端口诊断，日常无需点击。
验证成功后显示实际协议、出口与速率；IPv4 / IPv6 共享隧道及配额。显示“已保护”不等于连接成功，异常中断时普通应用仍受保护。
“断开并恢复直连”安全恢复直连；正常关闭窗口停止隧道并退出，系统服务空闲待命。只有经过核验才会显示已断开；操作异常时底部的“恢复直连（UAC）”始终可用。不要关闭系统防火墙。

设备与诊断
账号由管理员创建，不开放注册。默认三台设备，以账号实际限制为准；设备识别码来自本机公钥，不采集 MAC 或硬件序列号。旧身份被管理员删除后，重新输入密码登录会申请新身份，仍需有可用设备名额。
UU 自动发现和签名核验通过的程序保留直连。日常升级不需要修复 UU 权限或修改网卡；如有问题先展开“诊断与测试”查看详情。
诊断默认收拢，系统维护另行收拢。GitHub 检查可提示 hosts / Steam++ 等本机接管，不会改 hosts 或关闭其他软件。复制的连接诊断不包含账号密码、令牌或密钥。

六个 UDP 入口诊断
“诊断与测试”中新增“一键诊断六个 UDP 入口”。请先断开连接；测试约 1—3 分钟，可取消，结束后保持断开。它复用本机已登记的身份，不增加设备名额，不改连接偏好，也不回退到其他传输方式。可复制脱敏报告；管理员后台可按诊断编号查看配对记录。服务器仅按需记录握手头计数，不保存密钥或业务内容，记录保留 7 天。客户端物理网卡层未采集，报告不能确定具体中间网络节点。

卸载与许可
卸载会恢复直连并删除共用服务及本机密钥；服务器设备历史与用量仍保留，需由管理员撤销旧设备释放名额。

启动入口只有 Proxy.exe。runtime/Proxy.Core.exe 是独立隧道进程，不能直接作为客户端打开；保留进程隔离以免界面崩溃影响连接保护，不会新增运行开销。
