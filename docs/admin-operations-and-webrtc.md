# 设备、出站保护、审计与 WebRTC

日常设备：创建用户账号后，由用户在Windows客户端确认归属，设备自动进入管理表。无需手工新建Peer。Peer是设备的加密隧道身份。表格“管理”同时打开识别码、接入说明和编辑区，可重命名、调整归属、撤销。换归属仍需新用户在客户端确认；撤销永久停用该密钥、释放名额，保留用量。高级手工公钥入口供外部WireGuard设备使用，不会生成或显示客户端私钥。

官方余额：只读Usage API将历史完整UTC日与今天已完成UTC小时分开查询，避免整月小时范围被API拒绝；小时查询受限或超时时明确退回完整日级截止，不把小时查询失败当作历史数据失效，每10分钟刷新；官方入账仍可能滞后。界面区分最近查询、用量最后变化、请求的账期截止。查询成功而金额不变可能是Oracle未新增记账，不是实时余额保证。原来按完整UTC日查询导致同一天一直使用相同截止，现已改进。

VPN预算：未校准时显示保守参考，不作为内核放行依据。参考从已验证官方用量按较大的二进制GB扣减，再把本月已采集的全部VNIC出站计入一次，减去配置的额度与安全余量；有意重复扣减以保守覆盖未入账尾部，不把不同单位冒称等价。首次在“历史用量处理”选官方保守校准，核对账期/安全余量并勾选确认，再保存；需要总量阻断时同时勾选启用。之后保留基线即可。也可手工输入核对后的用量。启用后达到阈值或采集缺口会停止全部VPN设备；管理后台和系统流量仍可能消耗额度。新月/缺口需重新校准。此机制不能承诺Oracle账单绝不超额，特别是采集前尚未入账的历史流量；安全余量须覆盖它。部署不自动启用保护或重设用户配额。

审计只展示最新10条，历史不删除。用户频次按近24小时的登录、确认、退出、客户端自报状态变化统计；每5秒的轮询不计数。状态变化为上报元数据，不是请求总量或收费依据。

WebRTC：全局TUN与WFP应使普通浏览器的STUN经Oracle或在故障时被阻断；UU有已核验直连例外。VPN不能阻止浏览器生成本地ICE候选，媒体权限、扩展和浏览器设置可能使内网地址暴露给脚本。公开检查页/ privacy-check/仅在点击后调用RTCPeerConnection，向固定Cloudflare/Google STUN发送少量请求，不请求媒体权限、不上传候选结果。无STUN响应必须标记不确定，不当作无泄漏证据。浏览器设置建议在页内说明，不静默改全局浏览器策略或破坏通话。Windows云端验收会启动独立临时Edge配置，通过真实RTCPeerConnection验证STUN公网候选为Oracle出口，不复用用户浏览器数据。

## 管理员设备分组、时间与登录保留（2026-10-25）

- 设备按客户端账号归组。同名（忽略大小写）的后台管理员账号置顶：本部署 `Morandi` 与 VPN 账号 `morandi` 对应。该标记仅控制展示，不授予客户端后台权限。可通过服务器配置 `ADMIN_DEVICE_ACCOUNT_USERNAME` 显式覆盖映射。
- 管理员自己的未确认设备留在管理员组。其他账号已登录但尚未确认的设备、无确认凭据的旧版或手工 Peer 单列“异常登记 / 待核查设备”。前者尚无隧道、不能连接、不占名额；后者可能已有手工接入，需查看详情。不能单凭未确认判断为攻击，云端测试及中断登录也会产生记录。陌生登录可通过重置所属账号密码使客户端会话失效；已有 Peer 可在管理详情中撤销。
- 容量统一显示十进制 GB/TB：1 GB = 10⁹ B，1 TB = 1000 GB。保存接口仍使用字节，已有配额不重置、不按新单位重新解释。编辑会从原字节数换算，可保留到 1 B。官方原始条目在诊断中保留原单位。Windows rc18 的 GiB 显示暂不改动，等待客户端视觉方案选定后统一呈现。
- 展示时间固定为北京时间 UTC+8；有效期编辑仍由浏览器本地 datetime-local 输入并转为绝对时间。账期继续采用 UTC 自然月。官方卡片“账单查询范围至”表示已请求的完整日期/小时范围，不保证已完整入账；“最近查询”是 API 请求时间。每约 10 分钟查询不等于实时记账，未入账流量仍需安全余量覆盖。
- 本地管理员成功登录后持久会话最长固定 30 天，不被轮询无限续期。Cookie 为 Secure/HttpOnly/SameSite=Lax，服务器仍核验管理员身份和密码哈希；主动退出会删除服务器会话，改密码也使旧会话失效。同密码的项目重新部署会复用已校验哈希，避免仅因重新生成随机盐而无故注销会话。无痕窗口关闭、清除浏览器 Cookie 后需要重新登录。上线前已存在的 1 小时会话不会被自动延长，需要正常再登录一次获得新期限。
- 本次仅调整上述功能布局，完整后台及 Windows 视觉风格需管理员选择初稿后再实施。

## 紧凑后台、用户分时图和删除设备（2026-10-25）

保留现有深色配色与导航；Windows 客户端无修改。功能说明集中到圆形 `!`：鼠标悬停、键盘聚焦或点击均可查看，Esc 关闭；手机可点开。保护未启用 / 已阻断、数据失效和操作错误仍直接显示。新建 / 编辑用户及保护策略表单按需展开，用户列表不再重复放置删除用户按钮，删除用户入口保留在编辑表单中。

点击用户名称展开图表，用单一下拉框切换“今日”（24 个小时）、“近7天”（每日）和“本月”（每日）。图表按 UTC 划分，与月额度账期一致；普通展示时间仍为北京时间 UTC+8。进度条始终表示共享月额度，系统没有凭空增加日限额或周限额。

原月累计完整保留。细分数据从本功能上线开始采集，早期只有月合计的数据不会倒推成每日数据；未采集部分和采样中断会标记不完整。采样间隔内的增量按采样入账小时计，正常细分每约30秒按需刷新；超过租约 / 重启或计数重置时，无法定位发生时间的流量只保留在原月累计，不硬塞到某一个小时。细分保留90天，不清除月累计或审计。

已纳管设备行和待确认登录行新增“删除”。未纳管的旧版 / 外部 Peer 需先通过“管理”登记归属；含网段路由的其他隧道不能当作普通设备误删。确认后会先永久撤销密钥、阻断访问，再移除运行中的 WireGuard Peer，注销该设备的全部登录会话并移出列表，释放名额。历史绑定、已用量、审计和密钥撤销记录保留；删除不会清空用户用量，旧密钥不能重新登记。为避免旧外部配置复活、地址冲突或被其他设备继承，旧隧道地址保留安全占位，不承诺立即复用；如以后再次接入，客户端需要生成新设备身份并重新确认。

服务器重启后仍会清除被旧外部 WireGuard 配置重新载入的已删除密钥。内核移除或 Web 数据库发生故障时，已落盘的撤销记录仍阻止重新接入，管理员可重试删除；后台不会仅仅隐藏仍允许使用的密钥。删除自己的当前设备会使 VPN 断开，属于操作的预期效果。
