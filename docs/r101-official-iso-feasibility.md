# R101 — evaluate authentic Microsoft ISO as a fallback to unresolved R99 VHD boot

**Not a test build, not an installer and not a release authorization.** Earlier free R97/R99 GitHub-hosted QEMU trials used the official Microsoft Server 2025 Evaluation VHD. Its UEFI Microsoft bootmanager, BCD and fallback files were present, and the exact native NVMe or IDE QEMU disk was verified attached. However, even with five minutes of initial boot plus reset, the offline Windows System.evtx showed ~456–458 ordinary Windows System events and **zero** Kernel-General 12 or EventLog 6005 boot-service records. R83 field activation remains blocked.

Rather than repeatedly rerun the same VHD, R101 separately evaluates whether the [Microsoft Evaluation Center official Windows Server 2025 English ISO](https://www.microsoft.com/en-us/evalcenter/download-windows-server-2025) can be obtained and validated in the same existing GitHub PUBLIC repo's standard FREE Ubuntu runner. The direct link from Microsoft's page is `https://go.microsoft.com/fwlink/?clcid=0x409&country=us&culture=en-us&linkid=2345730`. The trial lasts 180 days, requires respecting Microsoft terms and is not an automatic license purchase. <Link> not needed.

The one-shot CI requires an exact trusted GitHub public PR event, standard `ubuntu-24.04`, at least 32GiB temporary workspace headroom, and a 20-minute hard timeout. It follows HTTPS redirects only to explicit Microsoft-owned download hosts, caps the ISO download at 14GB and inspects its archive index only. A supported installation medium must have the x64 UEFI fallback loader, `sources/boot.wim` and `sources/install.wim` or `install.esd`. It never installs Windows, boots a VM, bypasses a login or security policy, connects guest networking, or installs a driver. **All bytes are discarded on job exit**; no artifact/cache/custom images or billable runner.

If this cheap foundation passes, a later specifically reviewed disposable VM trial can use that authentic Microsoft ISO to perform a fresh unattended but policy-compliant Windows evaluation installation, with locally generated ephemeral credentials, independent host-owned disk overlay and offline NT kernel witness. It must still never claim native Windows security tests until that kernel/boot gate passes. If source origin, download format or license is not verified, fail closed; do not use third-party ISOs or a paid provider. R100 host TAP airgap and R97 hypervisor rollback are already merged and should not be repeated needlessly. GA #34 OPEN, production `UnavailableProductionKernel` and R83 hard block stay intact; no user PC/UU/WireSock/Oracle changes.

**Sources:** [Official Windows Evaluation Center](https://www.microsoft.com/en-us/evalcenter/evaluate-windows-server-2025), [Microsoft no-cost trial information](https://info.microsoft.com/ww-landing-evaluate-windows-server-2025.html).
