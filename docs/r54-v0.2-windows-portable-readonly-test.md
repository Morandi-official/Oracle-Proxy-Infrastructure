# R54 — Windows v0.2 portable, no-admin test build

## Purpose

The user requested a Windows software test build by 2026-10-16 and
re-authorized GitHub-only development while avoiding changes to a
second physical Windows PC, whose browser/direct TCP 443 connectivity
has been unstable during prior R51 field checks.

R54 converts the existing WinForms preview into a **self-contained
portable, read-only v0.2 test build**. It is **not** yet a working
proxy or VPN and makes no network configuration changes. Do not
describe it as replacing WireSock.

## Change summary

- Replace `SanitizedDiagnostics`' subprocess call to Windows PowerShell
  with Windows-native C# code, Windows IP Helper `GetIpForwardTable2`
  using validated x64 ABI, read-only Win32 SCM service status queries
  and allowlisted process-name presence checks. No PowerShell, shell
  execution, no process-scoped `-ExecutionPolicy Bypass`, no .ps1 files
  in the distributed payload.
- Keep private addresses, DNS endpoints, routes, process IDs, MACs,
  local account paths, and WireGuard secrets out of both display and logs.
- Label hardware-type candidate adapters accurately; the app does NOT
  prove the physical network interface class, VPN connectivity or WFP.
- Build Windows 10/11 x64 portable GUI with self-contained .NET 8 and
  a README-first unsigned test-only manifest with executable SHA-256.
- Compile out all CI-only native tunnel/admin controls and prohibit
  packaged `wireguard.dll`, `tunnel.dll`, test SCM hosts and PowerShell.
- Run policy/protocol and **actual native Windows** diagnostics selftests
  on GitHub hosted Windows with Restricted policy marker. These tests
  only establish observation capability and package isolation.

## Acceptable user experience

The user can double-click `OracleProxy.Windows.Preview.exe` as an
ordinary user, refresh native read-only status and view explicit offline
policy simulations. Closing/deleting the portable folder uninstalls
the preview; no install or admin elevation is necessary.

If Windows SmartScreen or corporate application restrictions reject
the unsigned executable, the user must stop and keep existing security
protections enabled. No request to disable antivirus, bypass admin
policy or loosen execution policy.

## Release blockers

The actual Oracle VPN tunnel is not connected to the production GUI,
the full-device WFP kill switch and safe atomic Off remain unproven,
and R44–R50's true driver/DPAPI tests are lab-only. UU under full
protection, independent cross-network packet captures, code-signing,
signed installer, unattended crash recovery and real second-PC GUI
acceptance remain outstanding. GA issue #34 stays open.
