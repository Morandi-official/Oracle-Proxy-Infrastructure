# R97 — Free cloud Windows evaluation guest boot experiment

**User's condition:** absolutely no additional charges. R97 is restricted to the existing PUBLIC GitHub repository using the standard, free GitHub-hosted ubuntu-24.04 runner and an explicit 34-minute job timeout. It does not use any paid larger runner, Azure, new provider, signing service, paid Windows license, persistent custom runner image, artifact, cache, or Packages storage. GitHub's official billing documentation states that standard Actions runners are free for public repositories and that larger runners always cost money.

**Official image:** Tries the English VHD on [Microsoft Windows Server 2025 Evaluation Center](https://www.microsoft.com/en-us/evalcenter/evaluate-windows-server-2025). Microsoft's evaluation trial is free for 180 days. There is no form submission, Azure trial, Windows product key purchase, third-party ISO download or publishing of Microsoft images. If the download link requires registration or redirects to an unrecognized domain, abort.

**Isolation and rollback:** A disposable Ubuntu runner downloads to a temporary local folder, checks the Microsoft origin and known virtual disk formats, then may use QEMU/KVM to start a real guest with no network interface, loopback-only VNC, host-only QMP, a read-only official VHD backing disk and throwaway QCOW2 overlay. VM CPU/memory/disk are bounded. The host controls a VM hardware reset and, after shutdown, discards the entire QCOW2 overlay and rebuilds it from the base disk to check an independent reset-to-clean-state mechanism. Every file is destroyed during CI cleanup; images/screenshot files are never uploaded or cached. The temporary runner-only KVM user ACL is removed.

**Evidence limits:** Successful QMP query and a display framebuffer prove QEMU virtual hardware launched, NOT that Windows completed boot, login, guest-triggered reboot, WFP failsafe or WireGuardNT safe Off. If a real authenticated Windows boot observation is unavailable, CI explicitly logs no Windows kernel boot attestation. This is a no-network guest trial and performs no driver, WFP, DNS, route or UU action. Actual risky guest VPN/WFP work would require its own separate permission. GitHub-hosted nested virtualization is unsupported/experimental.

R83 production field hard stop and UnavailableProductionKernel remain unchanged, GA Issue #34 OPEN. Nothing touches Oracle wg0/NSG, physical Windows machines, WireSock/UU, their networks or Windows execution policy.
