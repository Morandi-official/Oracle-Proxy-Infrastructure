# Proxy rc28

普通用户入口统一为 Proxy；入口程序为 `Proxy.exe`，安装页、快捷方式与服务显示名称使用同一品牌。版本在窗口内以灰色显示，详细提交保留在诊断里。已有服务键名、受保护安装目录、核心文件名、设备密钥与加密存储保留，保证升级和回滚兼容；这不是隐藏公网 IP 的运营商归属，许可证与对应源码仍随包提供。

启动后先核对系统服务的完整构建版本；缺失或不匹配时自动请求 Windows 授权完成安装／升级，核验运行版本后再允许登录。安装版 EXE 已完成此步骤时不再重复申请 UAC。取消或失败停留在初始化页，由用户明确重试；同一窗口的重试会等待尚未结束的安装事务，不中断回滚、不自动反复授权。随后先登录，再显示连接、用量与设备。可勾选记住登录，最多为本次成功登录起 30 天；保存的是现有服务 SYSTEM-DPAPI 保护的服务器令牌，不存储密码。未勾选时，正常退出即清除本机登录；主动退出账号、服务器撤销或过期会清除记忆。未登记设备仍需确认归属后才可连接。旧版登录令牌不构成新版的记住登录授权，首次升级需重新登录一次。

断开先撤销隧道授权，再检查适配器状态。若保留的快速重连隧道检查失败，停止该核心；如系统仍保留本软件创建的适配器，服务使用已有受保护创建凭据核验固定 GUID、LUID、创建进程身份及退出状态，再调用固定恢复助手，最后重新验证适配器已移除。凭据不符、未知接口或最终验证失败时仍保留保护，不改其他软件的网卡。退出等待有期限且不阻塞界面；只有尚未发送命令的管道忙连接可重试，已提交但结果不明的操作继续要求新状态确认。

布局使用统一浅灰蓝背景、顶部导航与白色卡片；状态说明和六项指标有固定边界，避免状态轮询反复放大空白。诊断与测试默认折叠，展开后按等宽三列排列，系统维护再折叠一次；本机恢复入口在登录页与主界面均保持可用。

发布要求：真实 Windows 消息循环下验证登录前置、退出返回、密码框清空、30 天与服务器过期上限、相同网络 UDP 自适应、连续状态切换后的指标边界、最小窗口恢复按钮可达、安装升级/卸载、旧版 NET8→NET10 的 DPAPI 原字节及密钥保留，以及真实服务器双栈 WireGuard、DNS/STUN 与故障恢复。云端测试不能替代用户电脑上故障的最终复验。
