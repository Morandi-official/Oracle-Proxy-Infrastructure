## 界面

三个对齐区块：当前连接、账号与用量、诊断与测试。左侧可跳转，小窗口纵向滚动；紧凑 900×620 客户区及正常窗口均通过实际显示检查，无横向滚动。协议选择仅为自动、WireGuard UDP、QUIC / HTTP3；HTTPS 自动兜底，实际通道单独显示。

连接区显示当前验证通过的 Oracle 出口、隧道 HTTP 延迟、本机 VPN 网卡上下行速率。速率从本地接口 64 位计数和单调时间差计算，核心/计数重启时重新采样，断开或服务不可用时清空；不使用服务器月账单计数冒充实时速率。账号区集中登录/退出、用量进度与数值、到期日和已登记设备数（不是在线数量）。

## 实际 Oracle 协议与耗时

测试每轮显式停止旧核心并强制选择协议，不把 HTTPS 兜底当作该协议成功。

| 项目 | 第一次 | 第二次 | 第三次 |
| --- | ---: | ---: | ---: |
| 原生 WireGuard UDP 冷启动 | 3383 ms | 1851 ms | 1783 ms |
| 标准 HTTP3 冷启动 | 1757 ms | 2763 ms | 2758 ms |
| 原生 UDP 被阻断时，预备后的 HTTP3 重连 | 326 ms | 285 ms | 299 ms |

预备后的原生 UDP 点击连接为 572 ms。以上冷启动耗时包括点击到本次出口验证通过；预备后的重连另列，不能混为冷启动。**冷启动尚未达到 1 秒，云端结果也不能替代 MetaWise 手机热点实测。**

全部通过：原生 UDP、屏蔽 51820 时的原生 UDP443、HTTP3 ALPN/认证、各三次强制冷启动后的 Oracle 出口及新 DNS 查询；HTTP3 三次强制结束核心后恢复且未切 HTTPS；三通道分别通过 VPN 访问管理网站且普通程序物理绕行仍被阻断；真实本机 TUN 收发计数与出口字段；预备连接、暂时丢包、GUI 退出、服务崩溃、已有设备身份恢复、自动 HTTPS 兜底与账号用量联动。

## 安全边界与验收限制

Windows SYSTEM 服务、认证管道、SYSTEM DPAPI、WFP 常驻/启动保护、TUN 租约、非所有者访问拒绝、故障时 TCP/DNS 不绕行及升级回滚均通过。UU 的 19 条真实网易签名路径核验、目录权限修复和准确回滚检查通过；这不等于真实 UU 登录会话连续性验收。

仍为未签名候选版。IPv6 当前阻断，尚未交付完整 IPv6 出口；真实 UU 会话在核心/服务故障和物理重启时的连续性仍待实机确认。首次安装/升级服务需要 UAC；日常连接通过受身份验证的普通界面控制系统服务。
