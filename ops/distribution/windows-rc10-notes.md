Windows 10/11 x64 便携验收版；完整解压后打开 OracleProxy.exe，点击“安装 / 升级服务”完成 UAC。无需卸载旧版、再次修改 UU 权限或关闭防火墙。

本版修复原生 UDP 双端口重复握手：同一个 WireGuard 实例不再向两个端口复制同一份握手，而是在 WireGuard 自身生成新握手时尝试下一端口，避免主端口请求已到服务器、回复丢失时备用握手被防重放机制拒绝。出口验证成功的原生端口按物理网络短期记忆，后续核心启动优先使用；网络变化或缓存到期后重新探测。

收到当前核心的 WireGuard 握手回复后，保留正在进行的出口 HTTP 请求，最多12秒，避免3秒取消重来造成不必要的协议回退。HTTP/3外层通道就绪本身不会触发延期，只有 Oracle 出口 IP 验证通过才显示已连接。连接诊断新增 client_handshake_reply，实际使用的协议继续明确显示。

预备时先创建本核心持有的休眠网卡，不设置地址、接管路由、DNS 或数据会话；点击连接后才配置及授权。核心退出时释放句柄，不收养已有同名网卡。这会把首次 Windows 网卡创建开销移出预备后的点击过程。

可选自动、WireGuard UDP、QUIC / HTTP/3；HTTPS/TLS只自动兜底。首次主端口回复丢失时仍需等待 WireGuard 的新握手重试，不能承诺冷连接一秒。

云端验收新增“只丢弃51820回复，请求仍发往真实Oracle”的故障场景，要求保持原生UDP并经443验证出口、DNS、管理网站；再重建核心验证已成功端口的记忆。此包只会在完整主分支验收通过后发布。云端结果不能代表 MetaWise 中国移动热点已通过，需要实机复测。
