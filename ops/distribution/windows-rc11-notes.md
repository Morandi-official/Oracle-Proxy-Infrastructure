Windows 10/11 x64 便携验收版。完整解压，打开 OracleProxy.exe，点击“安装 / 升级服务”完成 UAC；无需卸载旧版或再次修改 UU 权限。

正常关闭窗口或点击“断开并退出”会通过已认证的系统服务停止核心、核验隧道清理、保存断开状态并恢复直连，再关闭界面。账号保留；系统服务空闲待命。只点“断开并恢复直连”仍保留快速重连。界面崩溃、强制结束和系统关机仍保留防泄漏意图。退出未能安全确认时，窗口会保留恢复指引。

原生 UDP 诊断新增按51820/443区分的握手发出、回复接收、无效/过期回复和数值 socket 错误计数；回退后保留失败尝试的计数。日志不导出报文、密钥或原始 stderr，每类事件最多记录32条。client_handshake_reply 指当前核心，HTTP/3成功后的true不代表之前的原生UDP已成功。

可选自动、WireGuard UDP、QUIC / HTTP/3，HTTPS/TLS仅自动兜底。rc10在MetaWise中国移动热点上的原生UDP仍未通过；本版为继续定位提供证据，不能把HTTP/3回退成功称为原生UDP修复。

rc11协议重试：显式选择UDP或HTTP/3后，新的连接会重新尝试所选协议，不复用上次回退至其他协议的预备核心；在下拉框再次选择相同项目也会触发重新探测。自动模式保留已验证备用通道的快速重连。协议选择仍有受限网络下的自动兜底，实际协议继续明确显示。
