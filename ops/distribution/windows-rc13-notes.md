新增“03 诊断与测试 → 原生 UDP 8443 测试”：断开后点击，再点击连接。该操作只向管理员服务器公布的固定8443端口发送原生 WireGuard，不包装为 QUIC，仍要求验证 Oracle 出口。正常 WireGuard / UDP 仍先尝试51820再443；重新选择正常协议会退出8443测试。失败时依然按策略自动兜底，实际连接协议明确显示。

出口验证增加独立等待期限，避免底层 HTTP 操作不响应取消时持续占住连接流程。当前核心收到 WireGuard 回复时仍最多保留12秒；仅 HTTP/3 承载握手不延长期限。QUIC TLS 失败增加固定超时、证书、其他错误类别，不输出令牌、原始错误或报文。
