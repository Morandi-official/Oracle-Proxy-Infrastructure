Windows 10/11 x64 便携验收版。旧版先断开退出，完整解压新版，打开 OracleProxy.exe，点击“安装 / 升级服务”完成 UAC。无需卸载、重新调整 UU 权限或修改物理网卡 MTU；账号与设备身份保留。

修复原生 UDP socket 重建后，已有 WireGuard 加密会话的数据在新握手之前被误判为过期、导致后续超时或回落的问题。接收限定实际发送过的 socket，旧端口过期握手仍拒绝，数据继续经过 WireGuard 加密验证；连接状态仍要求 Oracle 出口验证。错误计数覆盖已选中的 socket。

当前 IPv4-only WireGuard 内层 MTU1200，外层加密数据报预算1232字节；Windows TUN MTU1280。此修改不改变物理网卡或服务器端口。云端必须通过至少120秒的低MTU持续原生UDP8443验收：实际临时降低并恢复可丢弃 Windows 主机的物理MTU，验证批量HTTPS、普通DNS和绕过DNS代理的UDP报文，不允许核心替换或协议回落掩盖失败。云端通过不代替中国移动热点实机验收。

系统服务失败后按3、5、10秒退避重启，健康5分钟后重置失败计数，避免旧24小时策略多次失败后持续等待30秒。新核心清除旧探测失败次数，旧代待完成探测不阻塞新核心；诊断区分核心存续时长与初次出口验证耗时。
