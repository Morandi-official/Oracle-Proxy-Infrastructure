Windows x64 集成验收候选版 rc16，尚未完成正式版签名与全部实机验收。

- 优化原生 WireGuard / UDP 接收缓冲：每个连接使用固定数量的帧缓冲，减少高速收包时的临时内存分配和垃圾回收压力；保留当前 UDP8443、收发缓冲区及 MTU 策略。
- 排队报文完整性、短缓冲处理、握手重试、重绑定与并发检查通过。受控微基准的每帧分配约从4352字节降到256字节；此数字不是公网测速提升比例，也不代表跨境延迟下降。
- 官方 A1 带宽为每 OCPU 1 Gbps，规格表按 VCN 内部通信描述；当前两核实例分配2Gbps，并非到中国移动的保证速率。E2 Micro的公网50Mbps限制不适用于当前A1。

使用方法：旧版先断开退出，完整解压新版，打开 OracleProxy.exe 后点击“安装 / 升级服务”（UAC）。保留现有原生 UDP8443 设置。系统服务继续待命是预期行为；无需卸载或重新修复 UU 权限。

已知限制：IPv6 当前阻断；包未做发布者签名，保留 HTTPS 兜底与安全恢复入口。云端检查不能替代用户热点实测，不承诺2Gbps公网吞吐或消除伦敦与中国之间的地理延迟。
