Windows x64 集成验收候选版 rc17，尚未完成正式发布者签名与全部实机验收。

修复普通“WireGuard / UDP”选项清除可用8443设置的问题。日常选择 UDP 或自动模式时，界面使用服务器声明支持的原生8443；默认点击连接也会先确认端口选择，避免旧51820/443计划超时后才切换QUIC。已准备好的8443核心继续保留快速连接。

诊断中的8443按钮仅在断开且服务器支持时可用，避免连接过程中点击却无法切换。服务独立校验端口能力，不允许任意端口、命令或目的地址。UDP、QUIC、HTTPS兜底和防泄漏策略保留，不修改服务器、MTU或UU权限。

使用方法：旧版先断开退出，完整解压新版，打开 OracleProxy.exe，点击“安装 / 升级服务”（UAC）。日常直接选择“WireGuard / UDP”或“自动”再连接，无需再点8443诊断按钮；已有账号和本机密钥保留。
