升级：旧版先断开并退出，完整解压新版，打开 OracleProxy.exe，点击“安装 / 升级服务”并完成 UAC。保留原账号、设备身份与设备名额。新版会自动取得已纳管设备的独立隧道 IPv6 地址；两种流量共用账号配额、到期限制和服务器预算。诊断中的 ipv6_policy 应为 tunnel，已连接时 verified_exit_ipv6 应为上述 Oracle 地址。

客户端同时验证 IPv4 与 IPv6 HTTPS 出口后才显示已连接；服务器未就绪时仍按明确策略阻断 IPv6。IPv6 内层 MTU 为 1280，在小 MTU 网络中允许加密的 IPv4 外层报文分片，不放开普通应用的物理直连权限。
