rc22 将便携版 ZIP 和标准安装版 EXE 一并迁移到 .NET 10 LTS，固定 SDK 10.0.403、内置运行时 10.0.14。用户无需另行安装 .NET。微软公布的该 LTS 支持期到 2028-11-14。

本次保留既有隧道、Oracle 地址与防泄漏策略；增加从已发布 rc21 的 .NET 8 服务原位升级验收，检查 SYSTEM DPAPI、设备密钥、Windows owner、SCM 管道和服务重启。实际发布程序在空共享运行时目录下执行自检，BUILD.json 记录实际内置 Core/Desktop 框架版本。

修复核心异常退出后残留隧道接口的恢复路径。清理需要受保护的设备创建记录、固定 GUID/LUID 和已退出的 SYSTEM 创建进程证明；仅处理本产品拥有的接口，仍由 Windows 原生接口枚举确认清理完成后才解除防泄漏保护。

断开状态的预热核心异常退出时，只允许回收经原生查询确认没有可路由配置的本产品接口，兼容 Windows 自动生成的 IPv6 链路本地项目；不加防泄漏规则、不修改地址/路由/DNS，普通应用继续直连。更换核心前清除旧出口验证与延迟，避免显示过期的就绪状态。

首次 UDP 握手在已观测到重传且没有 socket 错误时，保留一次最长 12 秒的冷启动窗口，减少短暂丢包造成的不必要换核心。暖连接与已验证连接的故障预算不变；永久无响应的冷 UDP 路径可能比此前多等待约 4 秒才回退。

每周自动检查同一 LTS 的稳定补丁及支持期，发现更新时提醒维护；不会自动跨大版本、重启运行中的 VPN 或将未验收包上线。自包含软件仍需安装后续发布包才能获得运行时安全修复。

升级：先正常退出旧客户端，安装版运行 EXE；便携版完整解压后点击“安装 / 升级服务”。不要先卸载，以保留账号和设备身份。两种分发共用同一个系统服务。
