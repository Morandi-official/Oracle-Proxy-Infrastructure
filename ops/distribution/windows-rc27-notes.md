# Oracle Proxy 0.3.0-rc27

修复普通“自动 / WireGuard UDP”连接固定使用 8443、未尝试其他已配置端口的问题。普通连接使用 443 / 8443 自适应方案：优先复用同一网络近期通过出口验证的端口，否则先试 443；仅在 WireGuard 生成新的握手时尝试备用端口，不复制同一握手。

首次升级迁移旧版普通连接留下的 8443 固定设置及短期兜底缓存，保留账号、密钥、设备标识与保护状态。显式“原生 UDP 8443 测试”仍为单端口诊断；此次连接验收请重选普通“WireGuard / UDP”，不要点击该测试按钮。

连接诊断新增失败尝试的实际入口地址、开始时间和原生 UDP 端口顺序，避免将最终 HTTPS 的入口误认为之前 UDP 使用的地址。

提供便携 ZIP 和常规安装 EXE，自带 .NET 10 LTS。未签名预发行版。旧版先断开并退出；便携版完整解压后安装 / 升级服务，安装版运行 setup EXE 完成升级。

发布以主分支完整验收为前提，包括真实 Oracle WireGuard UDP、IPv4 / IPv6 出口、DNS / STUN、单端口故障与端口记忆，以及现有 QUIC / HTTPS 兜底、防泄漏、服务恢复和安装卸载检查。云端验证不等于当前热点已完成实机验收；本次不宣称 QUIC 8443 可以跨越当前网络对该端口的限制。
