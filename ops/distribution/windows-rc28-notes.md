# Proxy 0.3.0-rc28

- 打开软件先检查系统服务；缺失或版本不匹配时自动请求 Windows 授权完成安装／升级，核验后才允许登录。已匹配的服务不会重复安装。取消或失败留在初始化页，可明确重试。
- 登录页前置，可选择记住登录最多 30 天。保存加密服务器令牌，不保存密码；退出登录或过期清除记忆。首次从旧版升级需重新登录，保留本机密钥和已登记设备。
- 修复断开／退出时遗留本软件适配器导致进入恢复的问题：服务核验原有创建凭据，调用固定恢复助手并重新验证移除后才确认断开。所有权或最终检查不通过时仍保留保护，不改其他软件网卡。
- 界面统一为 Proxy，入口为 `Proxy.exe`；黑色软件名、灰色版本号、统一浅灰蓝背景与顶部导航。固定状态说明与六项指标边界，避免断开后大空白；诊断默认折叠，展开后按钮等宽。
- 保留 rc27 的 UDP 443／8443 自适应、IPv4／IPv6、UU 可信直连、QUIC／HTTPS 兜底及 .NET 10 LTS。已有内部服务标识和加密存储位置保持兼容，许可证及配套源码随包保留。

提供便携 ZIP 与安装 EXE。升级前请先断开并退出旧版；便携版完整解压后打开 `Proxy.exe`，安装版运行 setup EXE。新版自动准备服务，随后登录账号。未签名预发行版，Windows 仍可能显示未知发布者提示。

发布必须通过同一主分支提交的真实 Windows 登录／布局／升级卸载、系统服务与防泄漏、双栈 WireGuard、DNS／STUN、端口故障与通道回退验收。用户电脑上的断开及关闭问题仍需升级后复验。
