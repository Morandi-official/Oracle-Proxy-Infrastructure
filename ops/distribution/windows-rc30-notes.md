# Proxy 0.3.0-rc30

- 默认窗口增大并使用响应式双列：连接和账号设备并列，诊断位于下方。小屏保留滚动；维护和设备明细仍按需展开。双栈出口独立留足两行，避免 IPv6 被遮住；诊断按钮在不同窗口宽度等宽。
- 修复 rc29 的冷启动边界：服务已恢复记住登录，但账号数据尚未返回时，持续显示中性的准备页，数据就绪后一次性进入完整主界面；只有确实未登录或会话失效才显示登录页。覆盖服务重启、升级后启动和普通重新打开。沿用最多 30 天的加密令牌，不保存密码。
- 后台新增“FlClash · 仅 UDP”：为指定用户单独创建设备配置、复制导入链接、下载配置或撤销。占用原有设备名额，计入共享配额，支持 IPv4/IPv6；只有 WireGuard UDP 443，不含 QUIC、HTTPS 或 DIRECT 备用。链接与文件含接入凭据，请私下交付且每台设备单独创建。已下载配置也可通过撤销停用。
- FlClash 需启用 TUN，其系统权限、路由与故障保护由第三方应用管理；不继承 Proxy 的 WFP 保护或 UU 直连例外。导出规则仅约束导入配置中的通道，不承诺第三方应用关闭后的系统断网。
- 保留自研客户端 UDP 443/8443 自适应、QUIC/HTTPS 备用、登录前自动准备服务、IPv4/IPv6 和 .NET 10 LTS。

提供便携 ZIP 和安装 EXE。旧版先断开并退出；便携版完整解压到新目录，打开 `Proxy.exe`，或运行安装 EXE。新版在登录前自动检查/升级服务，需要时批准 Windows UAC。未签名预发行版。

发布绑定真实主分支 Windows/Oracle 验收与对应源码；独立 Mihomo 实测覆盖双栈 WireGuard UDP 443，以及 UDP 失败后没有直连或 TLS 备用。后台配置链接、私钥不会进入此发布包。
