# Proxy 0.3.0-rc31

- 在“诊断与测试”加入“一键诊断六个 UDP 入口”：两个公网 IP 各测试 UDP 443、8443、51820。逐个固定入口进行真实 WireGuard 与 IPv4/IPv6 出口验证；诊断期间不回退到 QUIC、HTTPS 或直连。
- 自动配对客户端握手收发、服务器网卡握手头计数、内核 Peer 握手与用量。后台“UDP 诊断”可按统一诊断编号查看和复制记录；时间统一 UTC+8。缺失或丢失采集记录标为观察不完整，不据此认定网络丢包。
- 仅在已断开且无需恢复时启动；复用已登记身份，不新增设备名额、不修改连接偏好、UU 权限或持久防火墙。测试可取消，关闭/断开会先停止诊断；普通后台预热不会与测试竞争同一身份。
- 服务器只按需采集握手头字段，不保留密钥、Cookie 内容、业务数据包或完整报文；有时长、容量和频率限制。后台记录保留 7 天，最多 2048 条。
- 客户端收包证据来自 UDP 套接字，未采集物理网卡数据。两端证据可以缩小问题范围，但不能直接确定具体运营商、路由器或中间丢包节点。

提供便携 ZIP 与安装 EXE。旧版先断开并退出；便携版完整解压到新目录后打开 Proxy.exe，或运行安装 EXE。登录前自动检查/升级服务，需要时批准 Windows UAC。仍为未签名预发行版，Windows 可能提示未知发布者或 SmartScreen。
