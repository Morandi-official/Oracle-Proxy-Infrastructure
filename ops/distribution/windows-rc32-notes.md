# Proxy 0.3.0-rc32

- 登录时先检查本机设备登记。未登记时自动申请名额并登记，成功后才显示连接页面；名额已满时停留在登录页，提示联系管理员删除旧设备。
- 已登记设备重复登录复用现有身份，不新增名额。手动输入账号密码遇到已撤销的旧身份时，申请新身份并重新检查名额；旧密钥保持撤销状态。
- 便携包顶层只保留 Proxy.exe。隧道和保护组件改名为 Proxy.Core.exe、Proxy.Guard.dll，放入 runtime 目录，无需手动启动。
- 修复握手索引诊断数据与 UDP 重试策略的兼容问题，保留既有重试时限，避免过早回退到其他传输方式。
- 保留独立隧道进程。旧版升级保留设备密钥和加密状态；服务升级失败可以回滚。安装前自动检查和升级服务，可能需要 Windows UAC 授权。

提供 Windows x64 安装版 EXE 与便携版 ZIP。请先断开并退出旧版，再运行安装程序；便携版请完整解压到新目录后打开 Proxy.exe，保留 runtime 目录。升级不必先卸载，以免删除本机身份。

仍为未签名预发行版，Windows 可能提示未知发布者或 SmartScreen。六入口诊断及现有 UDP、QUIC、HTTPS 连接方式保持可用；本次更新不宣称修复特定网络的 UDP 回程问题。
