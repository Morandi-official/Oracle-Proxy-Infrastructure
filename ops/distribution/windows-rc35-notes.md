# Proxy 0.3.0-rc35

- 修复“恢复直连（UAC）”在已断开、存在预备隧道时错误要求保护已启用的问题。
- 修复恢复失败后控制服务未恢复、重启时遗留网卡导致服务无法响应的问题；保留网卡归属、持久状态和清理验证。
- 恢复操作现在跟踪完成、失败或取消结果，避免重复提交，并在重新确认状态后恢复按钮与安全退出。
- 连接诊断新增快照年龄、控制服务实时状态和其他代理兼容性只读信息。不输出代理密码或 PAC 地址，不改动其他软件的进程、网卡、代理配置或防火墙规则。

支持覆盖升级，账号和已登记设备保留。下载 setup.exe 安装版或完整 zip 便携版，不单独替换内部文件。

详见仓库 `ops/distribution/windows-rc35-recovery-guide.md`。
