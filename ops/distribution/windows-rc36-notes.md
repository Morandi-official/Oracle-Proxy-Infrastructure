Windows rc36 预发布版，提供安装版和便携版。

- 修复普通应用仍选择物理默认路由、网页被防泄漏保护阻止的问题；连接状态要求 Windows 实际选择隧道路由。
- “断开并恢复直连”停止隧道和后台服务，保留主窗口，便于再次连接。
- 关闭窗口或窗口进程意外退出后自动清理连接并恢复直连；正常断网仍保留防泄漏保护。
- 下次主动连接可按需启动自身服务，无需重复 UAC；UAC 恢复保留为应急入口。
- 修复紧急恢复后的状态刷新，以及快速重连、升级和卸载遇到后台自动停止时的竞争。
- 保留主备入口、设备管理、端口选择与其他代理只读兼容性诊断。

主分支 Windows 验收通过后才发布此构建。此版本尚未使用发布者代码签名。
