Windows rc37 预发布版，提供安装版和便携版。

- 修复便携版首次启动、旧服务缺少启动权限时没有进入管理员初始化的问题。
- 修复新便携版恢复旧后台时出现 BUNDLE_INTEGRITY_FAILED；恢复前验证并更新完整后台文件，保留设备密钥和账号状态。
- 恢复后重新核对当前版本服务并登记窗口，避免登录按钮一直不可用。
- 初始化失败显示可复制的具体诊断，提示完整解压 runtime；失败窗口可以关闭。
- 管理员授权与维护等待不再阻塞界面；同一窗口的初始化与恢复请求按顺序执行，避免重复启动工作进程。
- 修复卸载遗漏 API 地址缓存的问题，完整卸载后可重新进行首次安装。
- 保留隧道路由检查、主备入口、端口选择、设备管理和防泄漏保护。

发布前要求实际便携包的首次启动、缺文件重试、旧版升级、UAC 恢复、重新登录可用及窗口关闭验收通过；安装版要求真实安装、升级、窗口启动与卸载验收通过，同时通过主分支真实网络验收。

Windows 云端使用真实程序和 SYSTEM 服务；普通用户权限单独验证。云端自动化未模拟本地标准用户的安全桌面凭据输入。此版本尚未使用发布者代码签名。
