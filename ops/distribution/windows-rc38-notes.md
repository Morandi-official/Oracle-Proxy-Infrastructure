Proxy 0.3.0-rc38

优化 UDP 连接、断开及本机控制通信，减少重复账号读取和无效等待。点击后立即显示正在处理；完成状态仍以真实出口验证、隧道清理和后台停止为准。

实际 Windows GUI 两轮验收：断开、恢复直连并停止后台为 491–677 毫秒；再次连接并显示出口已验证为 2163–2321 毫秒。连接尚未达到 1 秒；首次启动或账号校验过期后的连接仍需联网读取，耗时受网络影响。快速重连只复用同一存活窗口、同一设备的 20 秒内账号凭据，不保留隧道后台；每次重新建立隧道并验证 IPv4/IPv6 出口。

修复系统关闭消息可能跳过安全退出的问题。断开保留主窗口；关闭窗口时恢复直连并停止后台。

通过主分支真实 Windows 联网、六个 UDP 入口、ipcece、WebRTC 出口、关闭窗口、便携版首次启动/升级/UAC 恢复及安装版安装/升级/安全卸载验收。安装版和便携版使用同一份已验收程序。
