Proxy 0.3.0-rc39

两轮优化后，云端实际 Windows GUI 在后台完整退出后重新连接并显示出口验证完成，用时 1319 / 1294 毫秒；断开、恢复直连并停止后台，用时 700 / 525 毫秒。rc38 对照为重连 2163 / 2321 毫秒。本版约 1.3 秒，仍未稳定达到 1 秒；这里没有用较短的服务内部计时替代端到端结果。

连接改进：合并设备附加与连接请求，直接返回已验证状态；让私有双栈出口探测、适配器准备和防护安装中可独立的工作并行；使用 ReadyToRun 预编译；减少重复映像校验、首次后台维护和界面布局开销。首次完整校验后的二进制由 Windows 句柄阻止写入/删除，复用时仍核对当前文件身份。内部 TCP 默认不启用 Nagle，控制 API 已启用 NoDelay。

连接成功仍等待防护、路由和当前核心的 IPv4/IPv6 出口验证。账号证明仅在同一存活窗口/设备的原有 20 秒有效期内复用；长间隔或新窗口仍需读取账号状态。不同机器和网络的耗时会变化。

断开后恢复直连、停止后台并保留主窗口；关闭窗口时也恢复直连并停止后台。主分支真实联网、六个 UDP 入口、ipcece、WebRTC 出口、重复连接/断开、窗口退出、便携版首次启动/升级/UAC 恢复、安装版安装/升级/安全卸载均通过验收。安装版和便携版使用同一份已验收程序。
