Proxy 0.3.0-rc40

完成四轮连接路径排查与优化，保留 WireGuard 加密数据通道，并借鉴模块化核心及 QUIC/HTTP3 减少握手往返的做法。

最终主分支 Windows 实际界面测试：后台完全退出后，点击连接到显示出口验证完成，分别为 **1017 / 1438 毫秒**；断开、恢复直连并停止后台，分别为 **532 / 508 毫秒**。rc39 对照为连接1319 /1294毫秒、断开700 /525毫秒。本版仍未稳定达到每次1秒，不能只用较短的服务内部计时代表完整界面耗时。

剩余波动已定位到 Windows 原生 WintunCreateAdapter 调用：最终两轮为191 /828毫秒；上一轮还观察到174 /1052毫秒。私有核心就绪为56 /53毫秒。这个结果说明系统设备创建是当前主要波动来源，不是已证明的物理硬件极限，也不保证其他电脑或网络的连接时间。

本版改进：按产品实际配置注册核心模块；让独立的适配器准备、私有端点启动及防护安装并行；在隧道内竞争执行全新 HTTP3 与原有 HTTPS 双栈出口验证；延后非关键界面布局和诊断文本构建；为服务的阻塞管道读取、防火墙操作及控制请求预留工作线程。适配器清理保留原有完整流程，只有通过精确归属、空地址/路由与 DNS 缺失检查时才省去重复写入。

安全边界保留：完整证书验证、当前进程与连接代次匹配、IPv4及IPv6出口验证、防泄漏与路由归属检查、原有同一存活窗口20秒账号证明期限。HTTP3不启用0-RTT或会话票据缓存，失败时原 HTTPS 验证继续运行。测试为同一窗口短间隔重连；长间隔或新窗口仍需读取账号状态。

断开后停止后台并保留主窗口；关闭窗口时恢复直连并停止后台。最终主分支真实联网、六个UDP入口、ipcece、WebRTC出口、重复连接/断开、窗口退出、模拟双核调度、错误证书/出口及取消边界、便携版首次启动/升级/UAC恢复、安装版安装/升级/安全卸载均通过相应验收。安装版与便携版采用同一份已验收程序。
