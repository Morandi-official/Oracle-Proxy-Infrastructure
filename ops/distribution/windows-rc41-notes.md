Proxy 0.3.0-rc41

支持后台按账号设置主入口、备用入口或双入口权限，以及双入口的默认连接顺序。客户端会为每个获准入口选择相应的服务器公钥，并在入口权限变更后刷新连接状态。UDP 诊断只测试该账号获准的入口。

入口权限由服务器独立的 WireGuard 身份与内核授权名单强制执行；手动修改地址或服务器公钥也不能使用未获授权的入口。双入口共享账号流量限额与限速。

FlClash 保持原订阅链接和设备密钥。新的双节点订阅支持后台权限切换，无需重新下载文件；默认顺序通过订阅刷新更新。旧的单节点本地配置需要首次更新一次原订阅，之后无需反复导入。

提供 Windows x64 便携版和安装版。此版本仍为候选版，未签名。
