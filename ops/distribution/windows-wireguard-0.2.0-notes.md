# Proxy 0.2.0 · WireGuard · Windows x64

连接页以 MB/s 显示本机 VPN 网卡的实时下载和上传速率。账号用量显示本周期已用、剩余和账期。设备管理页可查看已登记设备并删除选中的设备，本机识别码显示在列表上方。

从旧版 WireGuard 升级时，先断开并退出客户端，再运行新版安装程序。使用便携版请完整解压后启动 Proxy.exe。系统服务升级可能需要管理员授权。

如果正在使用 Tailscale 版，请先断开并退出该客户端，再启动 WireGuard 版。

窗口打开且处于已断开状态时，客户端可保留一张空网卡以加快下次连接。此时网卡没有配置地址、路由或 DNS。关闭窗口后，客户端会释放网卡和持有它的进程。界面在验证代理出口后显示「已连接」。

Windows 安装程序和便携版尚未使用 Authenticode 发布者证书签名。可通过同页的 `SHA256SUMS.txt` 核对下载文件。
