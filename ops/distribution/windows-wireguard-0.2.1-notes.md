# Proxy 0.2.1 · WireGuard · Windows x64

- 修复和恢复 UU 权限前会确认本机 VPN 已安全断开。维护完成后重新识别 UU，保留登录会话。
- 改进自定义安装目录识别，修复受支持安装中 UU 程序继承的“修改”权限。通过签名和权限核验的 UU 程序按进程路径直连。
- 登录前验证账号服务的 HTTPS 路径。当前路径不可用时尝试备用路径，再提交登录凭据。

升级前请在要更新的 Windows 设备上断开并退出 Proxy。可选择安装程序，或完整解压便携包后启动 Proxy.exe。系统服务升级可能需要管理员授权。

安装程序和便携版尚未使用 Authenticode 发布者证书签名。可用同页的 `SHA256SUMS.txt` 核对下载文件。
