# Proxy 0.2.2 · WireGuard · Windows x64

- 改进 `ACCOUNT_API_UNREACHABLE` 的恢复。手动登录会给慢连接更多时间，断开时可尝试固定地址的 HTTPS，仍核验账号域名证书。客户端先用无凭据请求验证登录接口，再提交凭据。
- 登录诊断可分别显示账号验证、设备登记和账号 HTTPS 请求阶段。
- Windows 新增“当前连接 → 应用直连”。本机断开 VPN 时可添加或移除 EXE，可在文件选择框中粘贴完整路径。下次连接后所选应用直连。UU 安装目录权限检查未通过时也可单独选择实际运行的 UU 程序，保存时保留目录权限。可添加最多 12 个 EXE，辅助进程需分别添加。请在断开 VPN 后更新已选程序，再重新添加。

升级前请在要更新的 Windows 设备上断开并退出 Proxy。可选择安装程序，或完整解压便携包后启动 Proxy.exe。

安装程序和便携版尚未使用 Authenticode 发布者证书签名。可用同页的 `SHA256SUMS.txt` 核对下载文件。
