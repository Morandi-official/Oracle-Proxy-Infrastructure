服务器总量保护
所有 VPN 设备共享的总预算
Oracle 公示每月 10 TB 免费出站。此处 TB = 10¹² 字节，GiB = 2³⁰ 字节。仅一台实例也需要核对采集前的历史用量与官方报表延迟。账期采用 UTC 自然月。


使用方法：额度是整台服务器每月上限，安全余量用于预留给账单延迟和非VPN流量。首次选择“官方数据保守校准”，确认后保存；之后保留基线即可。达到可用预算或采集失效时，启用保护会阻断所有VPN设备，后台仍可访问。新月份或计数缺口后需重新校准。官方数据更新不会自动重置已执行预算。
