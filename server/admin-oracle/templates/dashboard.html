已有 Peer 先显示为未纳管；绑定用户后才执行该用户的限制。客户端登录只验证账号；用户确认本机名称和识别码后才登记公钥并占用名额，设备上限默认 3 台。也可在此手工填入本机公钥。撤销设备后阻断流量、保留用量记录并释放设备名额；该公钥不可再次使用。
